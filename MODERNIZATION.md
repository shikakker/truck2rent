# truck2rent — Preservation & Portfolio Roadmap

The repository contains a large interactive demo, JSON/XML data, image assets and multiple After Effects animation sources.

## 10 tasks

1. Establish date, product purpose, audience and exact contribution.
2. Preserve the current interactive demo as a historical snapshot.
3. Document the relationship between `data.json`, `data.xml` and rendered UI.
4. Audit the demo for embedded third-party assets/libraries and record attribution.
5. Export optimized video/GIF previews from the animation sources for portfolio browsing.
6. Capture the main rental/search/vehicle interaction states that actually exist.
7. Package images and motion previews without bloating the repository landing experience.
8. Explain historical technical constraints and avoid implying current production deployment.
9. Separate product-design, motion-design and implementation contributions in the README.
10. Use this as a logistics/mobility interaction case demonstrating end-to-end visual/product craft.

## Portfolio value

Strong historical project because it combines domain-specific UX, data-driven screens and substantial motion work.
